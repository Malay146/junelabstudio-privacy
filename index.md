# Brand Lab — Privacy Policy

_Last updated: 9 November 2026_

Brand Lab is a personal, single-user design tool built and run locally by Malay Patel. It is not a public app and has no other users.

## What it accesses

Using the Pinterest API with read-only permissions, Brand Lab reads the account owner's own Pinterest boards and pins. These are shown as images on a private moodboard canvas that is used to develop brand identities.

## What it does not do

- It does not access any other Pinterest user's private data.
- It does not create, edit or delete pins or boards.
- It does not sell, share or send data to third parties.
- It does not use data for advertising or tracking.

## Storage

Any data the tool retrieves is stored only on the owner's own computer. The owner can delete it at any time, and access can be revoked at any time in Pinterest settings.
